# Car Parts Stock System

## How to access the code

Download the .zip file attached (or under releases then Final Project Release), and open the ./Assignment fold and run the
package. In the package there are all the Java classes, minus the test classes. The project will run from SystemGUI.java,
as it is the only classes with main(String[] args) subroutine.

## Future plans

I will most likely work on this at some point as a side project to make it a better piece of software for my record. Some
things I would like to do which I didn't get time to do for this assignment, would be connecting it to an SQL database. I think
this would be a good implementation, and would make a lot of sense especially for this kind of program. Linking this to a
database would mean all the records of stock don't get wiped when the program closes. Something else could be giving
the user the ability to create their own custom stock items during runtime, I feel like this would be easier with the
addition of the database.

Something also worth looking into would be making the menus at least using Forms, but also using Javafx, which uses a
similar approach to styling to CSS with HTML.
